# Tierlist
A desktop app that lets you organize some data and put it on a customizable tiered list.
Developed in the Godot Engine (with Mono C#).
Extra controls are shown below the menu.
You can save & load entire projects (.save), individual tierlists (.tierlist) and individual data (.tierdata) as files.

# Project Structure
- scenes: custom Godot elements.
- scripts/core: essential classes that I use in every project.
- scripts/scaffold: base-classes and serializable data structures that don't relate to anything else directly.
- scripts/ui: all classes directly used in the ui.
- textures: background and default images used in the ui.
